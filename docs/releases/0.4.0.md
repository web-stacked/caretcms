# CaretCMS 0.4.0

CaretCMS 0.4.0 strengthens the full editing and publishing cycle for Astro
sites, from private drafts through verified deployment.

Editors can now reshape top-level Markdown prose by splitting, inserting,
merging, deleting, and undoing paragraph regions. Caret preserves untouched
frontmatter and body bytes, supports YAML multiline strings, detects stale
source before publication, and can resume an interrupted publish without
repeating completed steps.

Studio now handles large collections with pagination and cross-page search,
reports source-read failures per entry, and offers keyboard-complete creation,
deletion, history, and ordering controls. The inline editor and Studio browser
modules are strictly type-checked, with safer conflict recovery, upload
handling, preview synchronization, and accessible focus management.

Deployments can report accepted, deploying, failed, and live states using
provider evidence tied to the published commit or revisions. Core includes a
GitHub Deployments provider and a deterministic simulated provider for local
testing. Rebuild requests have bounded timeouts and supported adapters retain a
manual retry target after draft cleanup.

The Cloudflare package adds a SQLite-backed Durable Object storage adapter for
atomic entry, revision, history, index, and reorder operations. The existing KV
adapter remains available for single-writer deployments.

Authoritative identity providers can enforce write policies for editing,
publishing, deleting, collection management, and uploads. Policy mode isolates
drafts by editor and preflights bulk publication before applying any changes.

This release supports Astro 6 and Astro 7 and requires Node.js 22.12 or newer.
See the [changelog](https://github.com/web-stacked/caretcms/blob/v0.4.0/CHANGELOG.md)
for the complete list of changes and the migration notes for structured drafts
and publish recovery.
