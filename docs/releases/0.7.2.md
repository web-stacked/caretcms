# CaretCMS 0.7.2

Three fixes to what CaretCMS writes into your files, found by setting it up on
a new template from scratch. Install `@caretcms/core@0.7.2`; `@caretcms/caretize`
is 0.6.3. There is nothing to migrate.

## Editing a paragraph keeps its quotes

Astro's Markdown renders straight quotes as curly ones, so an edited paragraph
came back from the page with curly quotes the author never wrote. Publish now
keeps the quotes the file was written with: a paragraph written with straight
quotes stays straight, and one written with curly quotes is left as it is.

The one trade-off: if an editor deliberately types a curly quote into a
paragraph written with straight ones, it is straightened.

## JSON data files keep their layout

Adding or removing an entry in a JSON file (an FAQ or pricing list written one
object per line) used to rewrite the whole file with every object spread over
several lines. A new item is now written in the style of the ones before it,
and a removed item takes only its own line. Adding one FAQ entry and editing an
answer changed three lines of the file.

## caretize names JSON it can't wire

When a project imports a JSON file as plain data
(`import site from "@/data/site.json"`), caretize now lists the file and where
it is used, and says why nothing on the page edits it. Moving the file into a
content collection with a `file()` loader makes it editable.

The [changelog](https://github.com/web-stacked/caretcms/blob/v0.7.2/CHANGELOG.md)
lists every change.
