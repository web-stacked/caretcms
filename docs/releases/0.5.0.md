# CaretCMS 0.5.0

CaretCMS 0.5.0 makes the Studio and inline editor calmer, clearer, and easier
to use across desktop and mobile without changing the underlying content and
delivery guarantees.

Studio now has compact collection switching, title-first entry creation with
editable slug suggestions, recognizable entry cards, and clearer collection
arrangement. Collection configuration can provide `entryLabel`, `titleField`,
`thumbnailField`, and `subtitleField` so each project uses its own language and
the most useful entry metadata.

Entry forms can use schema-defined sections and field descriptions. HTML fields
open in a sanitized formatted editor with optional source access. Image upload
and URL entry share one control, alternative text stays visible, and technical
metadata moves into a secondary disclosure. Repeatable records use compact
summaries and keep drag and keyboard movement available.

Save feedback now distinguishes unsaved browser changes, saved private drafts,
live changes, and entry visibility. Live saves, publication, discarding,
sign-out choices, deletion, version restoration, and conflict recovery use
focused product dialogs. Validation opens the relevant group and focuses the
first invalid field; conflicts identify changed fields and preserve local work.

The inline toolbar now offers explicit Edit and Preview modes. Its Studio drawer
can move to either side, expand to the full Studio, close without losing form
state, and follow selected content without reflowing the host page. Section
editing keeps frequent movement and insertion actions visible, moves occasional
actions into a More menu, and keeps insertion choices reachable above the fixed
toolbar at narrow viewport sizes.

The release was accepted through live Chrome review at desktop and mobile sizes.
It supports Astro 6 and Astro 7 and requires Node.js 22.12 or newer. No migration
is required; the new collection presentation fields and schema grouping metadata
are optional.

The [changelog](https://github.com/web-stacked/caretcms/blob/v0.5.0/CHANGELOG.md)
contains the complete change list.
